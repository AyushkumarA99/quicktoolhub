## Brand & Style

This design system embodies a clean, modern, and high-efficiency utility studio tailored for seamless online productivity. It serves a broad audience spanning students, developers, writers, and digital professionals who demand fast, ad-uncluttered, precision tooling with immediate feedback.

The aesthetic blends crisp corporate clarity with approachable, modern SaaS refinement:
- **Atmosphere:** Airy, frictionless, trustworthy, and distraction-free.
- **Visual Personality:** Sharp, mathematically balanced layouts softened by generous radii, crisp borders, and subtle luminous category accents.
- **Design Movement:** Modern SaaS Minimalism layered with subtle ambient depth and micro-glow accents that clearly delineate distinct functional suites.

## Colors

The palette establishes an ultra-clean base with rich, purposeful accents that segment features without visual fatigue.

### Core Functional Colors
- **Primary:** Indigo Blue (`#4F46E5`), with active/hover at Rich Dark Indigo (`#4338CA`) and subtle container fills at `#EEF2FF`.
- **Secondary:** Sky Blue (`#0EA5E9`), with interactive hover at `#0284C7` and container tints at `#F0F9FF`.
- **Neutral Foreground:** Deep Navy (`#0F172A`) for primary headings, Slate Gray (`#334155`) for readable body text, and Muted Slate (`#64748B`) for helper text, counters, and metadata.
- **Canvas & Surface Fills:** Pure White (`#FFFFFF`) for active tool workspaces and cards, Light Slate (`#F8FAFC`) for page backgrounds, Ice Tint (`#F0F7FF`) for tool headers and highlights, and Soft Lavender (`#FAF5FF`) for premium utility modules.
- **Structural Borders:** Subtle Cool Gray (`#E2E8F0`) and muted dividers (`#F1F5F9`).

### Category Accents
Tool categories leverage vibrant thematic tints paired with ultra-light tinted container backgrounds for instant mental mapping:
- **Image Tools:** Sky Blue (`#0EA5E9`, container: `#F0F9FF`, border: `#BAE6FD`)
- **Text Tools:** Purple (`#9333EA`, container: `#FAF5FF`, border: `#E9D5FF`)
- **Calculators & Math:** Emerald (`#10B981`, container: `#ECFDF5`, border: `#A7F3D0`)
- **Student Tools:** Amber (`#F59E0B`, container: `#FFFBEB`, border: `#FDE68A`)
- **PDF Tools:** Rose (`#F43F5E`, container: `#FFF1F2`, border: `#FECDD3`)
- **Developer Tools:** Cyan (`#06B6D4`, container: `#ECFEFF`, border: `#A5F3FC`)

## Typography

The typographic hierarchy uses **Inter** throughout, optimizing for optical scanning speed, dense functional data display, and clean digital ergonomics. 

- **Headlines:** Set in high-contrast weights (`700` and `800`) with tight letter spacing (`-0.025em` to `-0.015em`) in Deep Navy (`#0F172A`) to ensure rapid orientation.
- **Body:** Kept at a comfortable 15px base size (`body-md`) with generous 1.6x line heights in Slate Gray (`#334155`) for frictionless reading through multi-step outputs and calculations.
- **Code & Syntax:** Employs **JetBrains Mono** for developer tool outputs (JSON formatters, regex analyzers, base64 converters) to ensure fixed-pitch precision.

## Layout & Spacing

The layout is built on a responsive 12-column fluid grid system bounded by a max-width container of `1280px` for optimal ergonomic reach and content cohesion.

- **Breakpoints:**
  - `Desktop (>= 1024px)`: 12-column grid, `2.5rem` section spacing, `1.5rem` gutters.
  - `Tablet (768px - 1023px)`: 8-column grid, `2rem` section spacing, `1.25rem` gutters.
  - `Mobile (< 768px)`: 4-column single-column flow, `1rem` gutters, and `1rem` outer canvas padding.
- **Workspace Layout:** Interactive utility pages adopt a split workbench layout on desktop (60% active input/settings pane, 40% live preview/output pane) that collapses into stacked sequential cards on mobile devices.

## Elevation & Depth

Visual hierarchy combines low-contrast outlines with ultra-soft ambient blue-tinted drop shadows, eliminating stark flat divisions while maintaining light, clean airiness.

- **Level 0 (Flat/Base):** Canvas surfaces and secondary input zones sitting flush on `#F8FAFC` using a crisp `1px solid #E2E8F0` border.
- **Level 1 (Card & Tool Surface):** Workspaces and tool cards resting at pure `#FFFFFF` featuring `1px solid #E2E8F0` and `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`.
- **Level 2 (Hover & Active Lift):** Cards lift smoothly upon mouse encounter with `transform: translateY(-2px)` accompanied by `box-shadow: 0 10px 25px -5px rgba(15, 23, 42, 0.06), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Modals, Overlays & Command Bar):** Popovers, converter dropdowns, and modals feature deep diffusion: `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)` wrapped with an inner border of `rgba(255, 255, 255, 0.8)`.

## Shapes

The design system incorporates modern, friendly geometric curves:
- **Cards & Workspace Panels:** Styled consistently with `rounded-2xl` (`1rem` / `16px`), providing an inviting, polished container.
- **Inputs & Action Elements:** Form controls, action buttons, and segmented pickers utilize `rounded-xl` (`0.75rem` / `12px`).
- **Category Chips, Badges & Pill Tags:** Set to fully rounded circular caps (`rounded-full` / `9999px`) to maintain distinct visual semantics separating operational controls from informational tags.

## Components

### Buttons
- **Primary:** Background `#4F46E5`, text `#FFFFFF`, font weight `600`, radius `rounded-xl`. Transitions smoothly on hover to `#4338CA` with subtle shadow `0 4px 12px rgba(79, 70, 229, 0.25)`.
- **Secondary:** Background `#F0F7FF`, text `#0EA5E9`, border `1px solid #BAE6FD`. Hover shifts to `#E0F2FE` with text `#0284C7`.
- **Ghost/Tertiary:** Background `transparent`, text `#334155`. Hover transitions to `#F1F5F9`.

### Category Chips & Pill Tags
- Fully rounded pills (`rounded-full`) with `padding: 0.25rem 0.75rem`, `label-sm` font.
- Composed of category tint backgrounds with matching 15% opacity border and vibrant text (e.g., Image tools use `#F0F9FF` background, `#BAE6FD` border, `#0284C7` text).

### Cards & Tool Modules
- Built on `rounded-2xl`, background `#FFFFFF`, border `1px solid #E2E8F0`.
- Includes inner padding of `1.5rem` (`space-lg`).
- Interactive tool cards feature a top icon badge with the category's accent wash, heading in `#0F172A`, helper text in `#64748B`, and smooth hover transformation with a `-2px` vertical lift and soft blue shadow tint.

### Inputs & Text Areas
- Background `#FFFFFF`, border `1px solid #CBD5E1`, radius `rounded-xl`, padding `0.75rem 1rem`.
- Focus state applies a crisp ring: `border-color: #4F46E5` accompanied by `box-shadow: 0 0 0 3px rgba(79, 70, 229, 0.15)`.
- Monospace variant enabled for developer formatters with JetBrains Mono, tab size 2, and subtle slate background `#F8FAFC`.

### Checkboxes & Radios
- Size `20px x 20px`, border `1.5px solid #CBD5E1`, radius `rounded-md` (radios `rounded-full`).
- Checked state transitions to primary fill `#4F46E5` displaying a crisp white SVG icon.

### Live Utility Output Box
- Dedicated read-only or copyable container using `#F8FAFC` background with a subtle dashed or solid `#E2E8F0` border, quick-copy button positioned top-right, and an integrated counter badge (word count, file size, or byte indicator) at the bottom right.
