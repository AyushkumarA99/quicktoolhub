warning Common JSON Syntax Errors to Avoid

  • Trailing Commas: JSON prohibits a trailing comma after the last key-value pair or array item.
  • Single Quotes: All JSON keys and string values must be enclosed in standard double quotes "...", not single quotes '...'.
  • Unquoted Keys: JavaScript object keys can be unquoted, but standard JSON strictly requires quoted keys.
